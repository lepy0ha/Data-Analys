В этом репозитории собраны выполненные мной проекты, демонстрирующие мои компетенции в сфере дата-аналитики.

## Структура репозитория
### 1. Анализ рынка недвижимости Санкт-Петербурга  
Проект, демонстрирующий основные навыки исследовательского анализа данных (EDA) и их визуализации.  

**Стек:** Python, Pandas, Matplotlib  
**Сфера деятельности:** интернет-сервисы, площадки объявлений  
**Направление:** Data-аналитик, Fraud-аналитик, маркетинг-аналитик  

---

### 2. Приоритизация гипотез по увеличению выручки интернет-магазина и анализ результатов A/B-теста  
Проект, демонстрирующий навыки владения фреймворками для приоритизации гипотез, анализа результатов A/B-теста и проверки статистических гипотез.  

**Стек:** Python, Pandas, Matplotlib, SciPy  
**Сфера деятельности:** e-commerce  
**Направление:** маркетинг-аналитик  

---

### 3. Исследование рынка заведений общественного питания Москвы  
Проект, демонстрирующий навыки предварительной обработки данных, декомпозиции, визуализации и загрузки данных из облачных ресурсов.  

**Стек:** Python, Pandas, Seaborn, Plotly  
**Сфера деятельности:** офлайн-бизнесы, ресторанные стартапы  
**Направление:** Data-аналитик, аналитик-универсал, маркетинг-аналитик  

---

### 4. Классификация фишинговых сайтов  
Проект по построению модели, определяющей, является ли веб-страница фишинговой, на основе комбинации URL-признаков и HTML-контента. Показаны этапы подготовки данных, создание признаков, балансировка классов (SMOTE), сравнение моделей **Gradient Boosting** и **XGBoost** по метрикам F1 и ROC-AUC.  

**Стек:** Python, Pandas, scikit-learn, XGBoost, Imbalanced-learn  
**Сфера деятельности:** кибербезопасность, финтех, e-commerce  
**Направление:** Data Scientist, Security-аналитик, ML Engineer  

---

### 5. Детекция мошеннических транзакций (IEEE‑CIS Fraud Detection)

Проект по выявлению мошеннических онлайн‑платежей на базе публичного соревновательного датасета IEEE‑CIS Fraud Detection (Kaggle). Реализована очистка и объединение транзакционных и идентификационных таблиц, масштабная генерация новых признаков (временные лаги, частоты, TF‑IDF для email‑доменов), борьба с дисбалансом классов и ансамбль LightGBM + CatBoost. Добавлены интерпретации модели через SHAP.

**Стек:** Python, Pandas, LightGBM, CatBoost, Featuretools, SHAP
**Сфера деятельности:** финтех, платёжные шлюзы, банки
**Направление:** риск‑аналитик, Fraud Data Scientist, ML Engineer
